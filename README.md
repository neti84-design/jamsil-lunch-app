# 🍱 오늘잠심 — 잠실점심

**구내식당 공사 이슈로 인한 식사 문제 해결을 위한 어플!** 잠실역 직장인을 위한 점심 식당 찾기 + 실시간 웨이팅·후기 공유 앱.

## 기능

- **인당 예산** 필터 (8천 / 1만 / 1.2만 / 1.5만 / 2만 / 3만원 / 전체) — 예산 넘는 메뉴는 빨간색 표시
- **종류**: 한식 · 일식 · 중식 · 양식 · 아시안 · 샐러드 · 분식 · 기타 (캐치테이블·테이블링의 1차 분류와 동일)
- **메뉴**: 국밥·탕 · 백반·정식 · 고기·구이 · 면·국수 · 돈까스 · 라멘·우동 · 초밥·회 · 중식·마라 · 피자·버거 · 파스타 · 샐러드·포케 · 분식·김밥 · 도시락 · 샤브·전골 · 쌀국수·태국 (데이터의 세부 분류·대표 메뉴에서 자동 추출)
- **방문 목적** (캐치테이블 "방문 목적" 태그 방식): 빠른 점심 · 든든한 한 끼 · 고기·육식 · 해장 · 가볍게 · 건강식 · 샐러드·포케
- **좌석·편의** (테이블링 "편의시설" 항목 방식): **단체석(인원 선택 4~20명)** / **룸**
- 🛵 **배달**: 배달 되는 곳은 카드·상세에 "배달" 표시. 식당 상세의 "배달 돼요"를 한 명이라도 체크하면 붙고, 검색의 🛵 배달 빠른 필터로 모아보기
- 💬 **공유톡**: 관리자가 한 줄 질문·공지를 올리면 홈 검색창 바로 아래에 뜸. 질문은 한 줄 답을 달 수 있고(사람들 답은 옆으로 넘겨 보기, 실시간), 단순 공지는 댓글을 닫아 둠. 관리자 화면 "💬 공유톡" 탭에서 올리기·댓글 열기/닫기·삭제
- **도보 거리** (본사 롯데캐슬골드·잠실역 8번 출구 기준, 큰길 건너면 +3분·롯데월드몰/백화점은 건물 안 이동 시간 추가, 5/10/15/20분/전체) + 지도에 반경 표시
- **처음 기준은 인당 1.2만원 · 도보 10분 이내** (검색·지도 모두). 세부조건에서 바꾸거나 "초기화"로 되돌림
- ☀️ **오늘의 추천** (하단 메뉴): 점심때(12시) 잠실 날씨(Open-Meteo, 키 불필요)와 요일을 보고 6곳 추천
  - 비·눈 → 가까운 곳·롯데월드몰/지하상가처럼 우산 없이 가는 곳의 국물 요리, 5도 이하 → 뜨끈한 국물, 27도 이상 → 냉면·초밥·샐러드
  - 날씨가 평범하면 요일 주제 (월 든든하게 · 화 가볍게 · 수 고기 · 목 색다르게 · 금 특별하게)
  - 지금 예산·도보 조건 안에서, 팀 별점·평점을 더하고 날마다 조금씩 섞어 고름. "이 중에서 투표 만들기"로 바로 투표
- 🗳️ **점심 투표**: 후보 식당(2~12곳)을 담아 투표를 만들고 🔗 링크로 공유 → 받은 사람은 링크를 열어 가고 싶은 곳을 눌러 투표 (여러 곳 가능, 실시간 집계, 1등 👑)
  - 후보 담기: 투표 화면에서 이름 검색 · 오늘의 추천/관심매장/최근 본 식당에서 바로, 또는 식당 상세의 "🗳️ 투표에 담기"
  - 링크를 받은 사람도 후보를 추가할 수 있고, 내가 만들었거나 받은 투표는 "오늘의 추천" 탭의 "점심 투표"에 남음 (`supabase/schema.sql` v5 필요)
- 식당 상세: 가격·메뉴, 평소 웨이팅, 예약 방법(전화/네이버/캐치테이블/테이블링/바로 방문), 좌석(단체 최대 인원·룸), 영업시간, 연락처(바로 전화), 리뷰 요약·평점, 네이버지도/카카오맵 바로가기
- 🔴 **실시간 웨이팅**: 식당 상세에서 한 줄로 "앞에 N팀 · 약 N분" 제보 → 목록 상단에 세로로 최근 5건, 카드에도 바로 반영 (3시간 유지)
- 🍽️ **숨은맛집 / 역시맛집 체크**: 먹어본 사람이 한 기기당 한 번 체크, 카드와 메인 목록에 실시간 집계
- 💬 **한 줄 후기**: 별점 + 한 줄, 닉네임 없음. 내가 쓴 글은 "내 후기"로 표시되고 내가 지울 수 있음
- 🛠️ **관리자 모드**: 화면 하단 "관리자" → 비밀번호 입력 → 모든 후기·제보·체크를 한 곳에서 보고 삭제
- 📊 **별점 많은 순** 기본 정렬: 팀 별점 합계 + 맛집 체크 수가 많은 곳이 위로, 새 후기가 들어오면 실시간으로 순서가 바뀜
- 🟢 영업 상태: 네이버 지도처럼 **영업 중 / 마감 1시간 전 / 브레이크타임 / 영업 전 / 영업 종료 / 오늘 휴무** 를 한국 시간 기준으로 계산해 카드·상세에 표시 (영업시간 문자열을 해석, 미확인 가게는 표시 안 함)
- 하단 메뉴: **홈 · 검색 · 지도 · 오늘의 추천 · 관심매장**
  - 홈: 공유톡(검색창 바로 아래), 음식 카테고리 아이콘(국밥·탕, 돈까스 …), **건물별 모아보기**(5곳 이상 모인 장미상가·롯데월드몰), 최근 본 식당, 실시간 웨이팅, 지금 영업 중인 가까운 매장
  - 검색: 검색 버튼·키보드 "검색" 키, 최근 검색어(개별/전체 삭제), **별점순 · 가까운순 · 평점순 · 저렴한순** + **영업 중 · 배달** 빠른 필터, **세부조건**(예산·도보·종류·메뉴·방문 목적·좌석·주요장소) — 손가락으로 위로 끌면 따라 접히고, 목록을 내려도 접힘
  - 지도: 가까운 핀은 숫자로 묶어 표시, 처음엔 **도보 10분 이내**만 (세부조건 도보에서 바꾸기). 핀을 누르면 말풍선(이름·대표 메뉴 가격)과 아래 정보 줄 → 위로 올리면 식당 정보, 내리면 다시 지도
  - 오늘의 추천: 날씨·요일 추천 + 점심 투표
  - 관심매장: **나의 관심매장**(☆ 로 저장한 곳, 이 기기) / **동료 추천매장**(동료들의 관심 저장·숨은/역시맛집 체크·별점이 많은 곳, `supabase/schema.sql` v3 필요)
  - 홈의 주요장소·최근 본 식당 줄은 들어갔다 돌아와도 옆으로 넘겨 보던 위치 그대로
- 제목을 누르면 처음 화면으로
- ⭐ 찜, 검색, 정렬(별점 많은/평점 높은/가까운/저렴한 순), 모바일 대응 (목록/지도 탭)

## 배포 (Vercel)

주소: **https://jamsim.vercel.app**

1. https://vercel.com 로그인 → **Add New… → Project** → GitHub 저장소 `jamsil-lunch-app` **Import**
2. **Project Name** 을 `jamsim` 으로 변경 (→ `jamsim.vercel.app`)
3. Framework Preset 은 **Vite** 로 자동 인식됩니다 (`vercel.json` 에 빌드 설정 포함)
4. **Environment Variables** 에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 추가 (아래 Supabase 절 참고)
5. **Deploy** → 이후 `main` 브랜치에 푸시할 때마다 자동 재배포됩니다

프로젝트 이름은 Settings → General → Project Name 에서 나중에도 바꿀 수 있습니다.

## 실시간 제보·후기 연결 (Supabase, 5분)

키를 넣기 전에는 제보가 **내 기기(localStorage)에만** 저장되고 화면에 "이 기기에만 저장" 배지가 뜹니다.
팀원과 공유하려면 무료 Supabase 프로젝트를 하나 만들어 연결하세요.

1. https://supabase.com 가입 → **New project** (리전 Northeast Asia(Seoul) 권장)
2. 좌측 **SQL Editor** → `supabase/schema.sql` 내용 붙여넣고 **Run**
3. **Settings → API** 에서 `Project URL` 과 `anon public` 키 복사
4. 로컬 실행: 프로젝트 루트에 `.env` 파일 생성 (`.env.example` 참고)
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```
5. Vercel 배포: 프로젝트 **Settings → Environment Variables** 에
   `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 두 개를 추가 → **Redeploy** 하면 반영

동작 방식: `reports` 테이블 하나에 웨이팅 제보·후기·맛집 체크가 쌓이고, Supabase Realtime 으로 다른 사람의 제보가 새로고침 없이 바로 뜹니다.
익명 키로 누구나 읽기/쓰기가 가능하고, 삭제는 **본인 글(같은 기기)** 또는 **관리자 비밀번호**로만 가능합니다(RLS + 함수). 링크를 아는 사람만 쓰는 사내용 전제입니다.

### 관리자 비밀번호

`supabase/schema.sql` 안의 `insert into public.app_config ... 'change-me'` 줄의 값을 원하는 비밀번호로 바꿔 실행하세요.
이미 실행했다면 SQL Editor 에서 아래처럼 바꿀 수 있습니다.

```sql
update public.app_config set value = '새비밀번호' where key = 'admin_token';
```

앱 하단 "관리자" → 비밀번호 입력 → 모든 후기를 보고 지울 수 있습니다. 비밀번호는 이 기기에 저장되어 다음에도 유지됩니다.
Supabase 미연결(로컬 저장) 상태에서는 `.env` 의 `VITE_ADMIN_KEY`(기본값 `admin`)를 씁니다.

### 이미 v1 스키마를 실행했다면

`supabase/schema.sql` 을 그대로 다시 실행하면 됩니다. 새 컬럼(`wait_teams`, `tag`, `device_id`)과 함수가 추가되고 기존 데이터는 유지됩니다.
**공유톡·배달 체크는 v4** (`talk_posts`·`talk_comments` 테이블, 관리자 함수, `delivery` 태그) 가 필요하니 꼭 다시 실행하세요.
**점심 투표는 v5** (`polls`·`poll_votes` 테이블, 후보 추가·표 취소 함수) 가 필요합니다. 관리자 비밀번호 줄은 `on conflict do nothing` 이라 다시 실행해도 바뀌지 않습니다.

## 데이터

직접 정리한 식당(가격·메뉴·영업시간 포함)과 카카오맵에서 가져온 주변 음식점을 함께 보여줍니다.

단체석 최대 인원(`seating.groupSize`)과 룸 유무(`seating.room`)는 후기·매장 유형 기반 **추정값**이라 `estimated: true` 로 표시됩니다.
확인된 곳은 값을 고치고 `estimated` 를 지우면 "(추정)" 표시가 사라집니다.

- `src/data/restaurants.ts` 에 식당 목록이 들어 있습니다. 타입은 `src/types.ts` 참고.
- 검색 결과(다이닝코드·식신·테이블링·폴레·블로그 요약) 기반으로 수집한 초기 데이터라 **가격·영업시간·전화번호는 방문 전 확인**이 필요합니다.
  확인 안 된 값은 `null` 로 두었고, 각 항목의 `sources` 에 출처 URL이 있습니다.
- 좌표·카카오맵 링크·빈 전화번호는 카카오 장소 검색으로 보정했습니다 (2026-10, 82곳 중 70곳 매칭, 10곳은 주소 좌표).
  `approxLocation: true` 로 남은 곳(주소 미확인 2곳)은 근사치입니다. 식당을 추가한 뒤 아래 스크립트를 다시 돌리면 됩니다.

```bash
KAKAO_REST_KEY=발급키 node scripts/kakao-enrich.mjs                     # 미리보기 (매칭 결과만 출력)
KAKAO_REST_KEY=발급키 node scripts/kakao-enrich.mjs --apply             # 주소까지 일치한 곳만 반영
```

  이름이 다르게 등록됐거나 다른 지점만 잡히는 곳은 스크립트 안 `REVIEWED` 표에 확인 결과를 적어 둡니다.
  기존 전화번호는 덮어쓰지 않습니다 (비어 있을 때만 채움).

### 카카오맵 주변 음식점 (자동)

직접 정리한 식당 외에, 본사 반경 1km 안의 카카오맵 음식점(술집·카페·간식·구내식당 제외)을 `src/data/kakaoPlaces.ts` 로 가져와 함께 보여줍니다 (2026-10 기준 934곳).
카카오 검색 API엔 가격·메뉴·영업시간이 없어서, 카카오맵 가게 페이지가 쓰는 정보로 따로 채웁니다 (2026-10 기준 메뉴·가격 813곳, 영업시간 904곳).

```bash
NODE_USE_ENV_PROXY=1 node scripts/kakao-menu.mjs            # → src/data/kakaoDetails.ts (받아 둔 건 다시 안 받음, --fresh 로 전부 새로)
```

- 점심 가격대는 음료·사이드·3만원 넘는 큰 메뉴(전골 대·수육 등)를 빼고 계산합니다. 대표 메뉴도 그 안에서 고릅니다.
- 직접 정리한 곳(`restaurants.ts`)은 조사값을 그대로 두고, 비어 있는 메뉴·영업시간·카카오 별점만 채웁니다.
- 공식 API 가 아니라 카카오가 형식을 바꾸면 스크립트를 고쳐야 할 수 있습니다. 네트워크에서 `place-api.map.kakao.com` 이 허용돼야 합니다.
- 카카오맵에 메뉴가 없는 곳은 동료가 정리한 "오늘 뭐 먹지 — 점심외식 길라잡이 v1.1" 자료(`src/data/menuPrices.ts`)로 채웁니다.
- 그래도 가격을 모르는 곳은 "가격 미확인"으로 보이고, **예산 필터를 고르면 숨겨집니다**. 영업시간을 모르는 곳은 "지금 영업 중" 목록·오늘의 추천에 넣지 않습니다.

```bash
KAKAO_REST_KEY=발급키 node scripts/kakao-import.mjs        # 다시 가져오기 (반경 바꾸려면 뒤에 m 단위 숫자)
```
